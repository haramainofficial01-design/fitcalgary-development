# Product specification

FitCalgary Index launches as a public Calgary fitness index plus authenticated athlete, judge, moderator, trainer, and administrator workflows. Public users can browse gyms and transparent pricing, clubs, events, leaderboards, athletes, and verified results. Authenticated athletes can maintain privacy-aware profiles, privately save gyms, submit evidence, track decisions, resubmit, and receive notifications. Judges review only authorized evidence against versioned checklists. Administrators maintain all content and rules without source changes.

The authoritative service owns identity context, authorization, content, verification, ranks, notifications, analytics, and audit history. Web, iOS, Android, watchOS, and admin all consume it.

V1 does not include payments, betting, chat, a social feed, GPS tracking, HealthKit/GymKit, or a trainer marketplace. Real client content, detailed discipline standards, legal approval, and production credentials remain external inputs.
